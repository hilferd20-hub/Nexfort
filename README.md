# 📂 NX Files by [Nexfort.tech](https://nexfort.tech)

**NX Files** — это мощный автономный файловый менеджер, полноценная IDE и веб-терминал, упакованные в **один единственный PHP-скрипт**. Никаких баз данных, npm-пакетов или сложных настроек. Закинул на сервер — и работаешь.

Изначально утилита создавалась для инженеров платформы Nexfort, чтобы быстро править конфигурации на удаленных объектах прямо со смартфона, но теперь доступна для всех в формате Open Source.

## ✨ Ключевые возможности

*   📦 **Zero-dependency:** Вся логика, стили, иконки и даже Service Worker (для PWA) генерируются из одного `.php` файла.
*   📝 **Встроенная IDE:** Редактор кода на базе CodeMirror с подсветкой синтаксиса, поиском и заменой. Отлично адаптирован под мобильные устройства (поддержка `contenteditable`).
*   💻 **Реальный веб-терминал:** Выполняйте команды (Git, Composer, работа с файлами) прямо из браузера (использует `proc_open`).
*   🛡 **Умные бэкапы:** При каждом сохранении файла автоматически создается его резервная копия. Встроенный менеджер позволяет откатиться к любой версии в один клик.
*   📱 **PWA-Ready:** Устанавливается на экран смартфона или рабочий стол ПК как независимое приложение с оффлайн-заглушкой при потере сети.

## 🚀 Установка

1. Скачайте `install.php` из этого репозитория.
2. Загрузите его в нужную директорию вашего веб-сервера.
3. Откройте `http://ваш-домен/install.php` в браузере.
4. Придумайте надежный пароль и нажмите «Развернуть».
5. Скрипт сам сгенерирует файлы приложения (`index.php`, `sw.js`, `manifest.json`) и удалит всё лишнее.

## 📱 Использование на смартфоне
Мы уделили особое внимание мобильному UX.
*   Терминал автоматически сжимается при открытии экранной клавиатуры.
*   В редакторе реализованы специальные плавающие кнопки: «Скопировать», «Вставить» и «Выделить всё» для обхода ограничений Android WebView.

## 🔒 Безопасность
Поскольку скрипт дает реальный доступ к консоли сервера через терминал, настоятельно рекомендуется:
*   Использовать длинный и сложный пароль.
*   Работать **только по протоколу HTTPS** (иначе браузеры заблокируют функции буфера обмена и установку PWA).
